M'IAM — Gestionnaire de l'Agenda
Interface officielle de mise à jour des animations estivales de l'Île-aux-Moines.
(Dossier : Gestionevenements)
💡 Mode d'emploi simple :

0. Synchronisez : Cliquez sur le bouton noir « 🔄 Actualiser depuis GitHub » pour recharger la liste actuellement publiée en ligne avant de faire vos modifications.

1. Gérez la liste : Ajoutez de nouveaux événements ou corrigez les existants avec les boutons orange « Modifier » et rouge « Supprimer ».

2. Téléchargez : Une fois terminé, cliquez sur le gros bouton bleu ci‑dessous pour obtenir le fichier de mise à jour evenements.js.

3. Publiez : Dans le dossier Gestionevenements, renommez l’ancien fichier evenements.js (par exemple : evenements‑ancien.js) afin de conserver une copie de sauvegarde, puis glissez‑déposez le nouveau fichier téléchargé à la place.
Glissez ensuite ce fichier evenements.js dans votre dépôt GitHub (onglet Code), puis validez avec Commit changes.
L’application se met à jour automatiquement. Si la mise à jour ne s’affiche pas immédiatement, rechargez la page (Ctrl + F5).
📥 Étape terminale : Télécharger le fichier evenements.js mis à jour
